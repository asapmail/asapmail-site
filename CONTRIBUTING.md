# Contributing

1. Create a short-lived branch: `feat/*`, `fix/*`, or `chore/*`.
2. Make focused changes and never commit secrets.
3. Run `npm run check`, `npm run audit:prod`, and relevant browser tests.
4. Push the branch and open a pull request.
5. Review the Vercel preview and CI results.
6. Merge only after required checks pass.

Dependencies and copied UI components require source, license, diff, and security review.
